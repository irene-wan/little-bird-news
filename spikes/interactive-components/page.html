인터랙티브 설명 시험

소식 안에 들어갈 조작형 설명 세 가지(비교, 시뮬레이션, 과정)를 폰에서 직접 만져 보기 위한 페이지입니다. 읽으면서 아래를 봐 주세요.

  • 값이나 선택지를 바꾸면 결과가 바로 달라지나요?
  • 조작하다가 화면이 엉뚱하게 스크롤되거나, 스크롤하다가 값이 바뀌지 않나요?
  • 한 손 엄지로 누르기 편한가요?
  • 맨 아래 "실패 시험"을 눌렀을 때 깨진 화면 대신 요약 카드가 나오나요?

실패 시험

조작형 설명이 잘못 만들어졌거나 화면에 그리지 못했을 때를 일부러 일으킵니다. 이때 깨진 화면이나 글자만 있는 화면이 나오면 안 되고, 사실 목록으로 그린 요약 카드가 대신 나와야 합니다.

자동 점검

지금 이 기기 화면에서 각 설명의 값을 실제로 바꿔 보고, 결과가 달라지는지와 가로로 넘치지 않는지를 확인합니다.
